# 缺陷模板

- 缺陷 ID：BUG-阶段-序号
- 标题 / 对应任务与矩阵 ID：
- 创建时间 / 报告者：
- 严重度：S0 数据丢失或严重泄露；S1 P0 路径不可用/错引；S2 局部功能失效；S3 外观或文字问题
- 修复优先级（PM 指定，与严重度分开）：
- 归属：本地后端 / UI / 契约 / Provider / 待定位
- 环境：构建、契约、设备、系统、U/M/R/S/D
- 前置条件 / 测试文件 SHA256 / 输入：
- 最小复现步骤：
- 预期行为 / 实际行为 / 发生频率：
- 证据路径（截图、录屏、日志，脱敏）：
- 影响范围 / 临时绕行（如有）：
- 状态：OPEN → ASSIGNED → FIXED_PENDING_QA → VERIFIED；失败 REOPENED
- 开发修复交接与时间（由开发提交独立交接供 QA 引用）：
- QA 复测时间 / 构建 / 结果 / 证据：
- 受影响回归项与结果：
- 关闭依据 / PM 收口记录：

无执行证据的设计问题记录为 REVIEW，不伪造软件缺陷或 FAIL。
