## 样本与完成证据

M0-UI 交付后增补 `UI-INTEGRATION-CASES.md` 的 UI-T01–UI-T11，映射现有需求编号，不改变优先级或产品执行状态。设计冲突跟踪见 `M0-UI-REVIEW.md`。

使用自制或有许可 PDF：短文字教材、中文/英文双栏、含公式/图表、多级书签、无书签、扫描件、混合尺寸/旋转/裁剪页、24/25/26 页、大文件、损坏/加密文件。每份固定 SHA256、页数及人工核对的引用坐标。文本范围与几何范围同时核对。

AI 真实评估记录输入范围、Provider/模型、设置、实际回答、人工依据与失败原因；不以“HTTP 200”判定语义通过。关注文档忠实性、引用准确性、六段结构和继续阅读导航价值。重复次数及合格门槛在首次真实调用前由 PM/QA 定稿，M0 不虚构指标。

P0 发布验收必须有 R01–R10 的实际执行证据，特别是 R03 真机证据与真实 Provider 通路。用户已有 Mac/iPad，可后续配合；当前 Windows 没有 Xcode/Swift 构建证据，设备验证为待执行，不表示永久缺设备。
