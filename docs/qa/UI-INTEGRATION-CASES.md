## v0.2-revised 复核补充（全部 NOT_RUN）

- UI-T05：A文档第0页保存排队后打开B文档第0页；保存确认只归A。旧快照已提交时不忽略其savedRevision，新快照继续以正确expectedRevision提交。仅dirty标记、无快照数据时不得假称最新笔迹恢复。
- UI-T07：resolveSource等待期间切换/关闭/替换阅读器文档；有效旧结果返回后不导航新视口，也不绘旧高亮。全文重点入口执行相同验证。
- UI-T06/UI-T08：服务failed与用户cancelled分别注入，failed不再发送cancelAI；保留对应错误，重试新attempt且旧终态不能覆盖。
- UI-T11：删除资料分别选择保留/删除笔记，对应显式参数和实际持久化结果；Manifest的文字/图像/原件/embedding字段与真实传输匹配。Provider或范围变更后检查确认是否仍适用。
- UI-T01：窗口窄于540pt时仍能全宽阅读，540pt只作为分栏舒适门槛；Dynamic Type不截断主要操作，Reduce Motion禁用脉冲。
