# 提测 / 结果模板

## 开发提测

- 任务 ID / 标题：
- 时间（ISO 8601 +08:00） / 发送角色 / 接收角色：
- 已读取文件与 READ_ACK 日志：
- PRD 需求 ID / 契约版本：
- 构建标识（无 Git 时附文件 SHA256 清单）：
- 变更文件 / 所有权释放范围：
- 实现内容 / 已知限制 / 未实现需求：
- 环境与复现输入（不附密钥）：
- 开发自测命令与实际结果 / 证据路径：
- 未执行项及原因（必须区分 mock、真实 Provider、模拟器、真机）：
- 迁移 / 安装 / 配置步骤 / 恢复步骤：
- 申请 QA 范围 / 下一步：

## QA 执行记录（另建文件，保留提测原件）

- 结果 ID / 提测 ID / 验收矩阵 ID：
- 执行者 / 真实开始结束时间：
- 构建与契约 / 系统与设备 / 环境类别 U/M/R/S/D：
- Provider 与模型（如适用，不记录密钥）：
- 输入及步骤：
- 预期 / 实际：
- 状态：NOT_RUN（执行后按证据改为 PASS/FAIL/BLOCKED）
- 证据路径 / 缺陷 ID：
- 未测范围与恢复条件：
- 接收方 / 文件释放范围：
